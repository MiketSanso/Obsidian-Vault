# Понятия операционной системы

### 1. Процессы
   
   
   Для связи с операционной системой пользовательская программа должна сформировать системный вызов, который обеспечивает переход в режим ядра и активирует функйции операционной системы. После завершения работы управление возвращается пользовательской программе, команде следующей за системным вызовом. 
   
Процессом называют программу в момент выполнения. С каждым процессом связывается его адресное пространство. 

### 2. Адресное пространство 

Адресное пространство - список адресов в памяти от некоторого минимума до некоторого максимума, который процесс может прочесть и в которые он может писать

Адресное пространство содержит саму программу и данные к ней. 

Со всяким процессом связывается некий набор регистров, включая счётчик команд, указатель стека и другие аппаратные регистры. 
Во многих операционных системах вся информация о каждом процессе, дополнительная к содержимому его собственного адресного пространства хранится в таблице операционной системы.

Таблица представляет собой массив структур по одной на каждый существующий на данный момент процесс

Главными системными вызовами, управляющими процессами, связанными с началом и окончанием процесса

ВЗАИМОБЛОКИРОВКА

Управление памятью связано с управлением адресным пространством процесса.

### 4 Ввод-вывод данных

Каждая операционная система имеет свою подсистему ввода-вывода для управления устройствами ввода-вывода. Некоторые из программ ввода-вывода являются независимыми от устройств. Другая часть программного обеспечения , в которую входят драйверы устройств, предназначена для определённого устройства ввода-вывода

### 5. Файлы

Основной функцией операционной системы является скрытие особенности дисков и других устройств ввода-вывода и предоставления пользователю понятной и удобной модели устройств файлов. Системные вызовы необходимы для создания, удаления, чтения, записи файлов. 

Предоставляя место для хранения файлов OC использует понятие каталога как способ объединения файлов в группы. 

ЗАМЕЧАНИЕ - Каждый файл в иерархии каталогов можно определить, задав полное имя файла

### 9. Интерфейс прикладного программирования

Программа Windows, как правильно, управляется событиями. Основная программа ждёт, пока возникнет какое-либо событие, а затем вызывает процедуру для его обработки (Нажатие, перемещение курсора и т.д.)

Затем для обслуживания события вызываются обработчики. 

Интерфейс прикладного программирования - это набор готовых классов, процедур функций, структур и констант, предоставляемых приложением для использования во внешних программных продуктах.
